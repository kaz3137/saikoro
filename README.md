# サイコロ GitHub Pages向けPWAパッケージ

サイコロ ver.1（実用版）と ver.2（物理演算版）の、GitHub Pages などの静的ホスティングにそのまま置ける配布パッケージです。サーバー処理は不要で、履歴・設定は利用者ごとの端末内（localStorage）に保存されます。

## 構成

- `index.html` — 入口ページ（ver.1 / ver.2 へのリンク）
- `v1/` — サイコロ ver.1：単独で完結する静的ページ＋PWA（manifest / Service Worker / アイコン）
- `v2/` — サイコロ ver.2：物理演算版＋PWA。Three.js と cannon-es は CDN（jsDelivr）から読み込みます

## GitHub Pages への置き方

1. GitHub でリポジトリを作成する（Public）。
2. この ZIP を解凍し、中身一式（`index.html`、`v1/`、`v2/`）をリポジトリのルートにアップロードする。
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定する。
4. 数分後に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を共有する。LINE にはこの URL を貼れば、受け取った人がタップしてそのまま使えます。

リポジトリ名をサブパスにする場合でも、各アプリは相対パスで動作します。ver.1 / ver.2 を単独で公開したい場合は、そのフォルダの中身だけをルートに置いてください。

## PWA（iPhone）

- Safari で開き、共有メニュー →「ホーム画面に追加」でホーム画面から起動できます。
- ver.1 はオフラインでも動作します。ver.2 は初回に CDN からライブラリを読み込むため通信が必要で、読み込み後は Service Worker のキャッシュで再訪が速くなります。
- iOS の仕様で、長期間使われない Web アプリの保存データは消去されることがあり、その場合は設定・履歴が初期化されます。

## 仕様メモ

- ver.1：d4/d6/d8/d10/d12/d20、各0〜20個・合計最大120個。暗号乱数（crypto.getRandomValues）＋棄却サンプリングで全目等確率。固定フッターの「前回の合計」は、現在の構成が前回の抽選構成と一致すれば「設定変更あり」を表示しません（構成の比較で判定）。
- ver.2：合計最大20個（種類ごとの上限なし）。投げ出しの位置・初速・回転は暗号乱数、結果は物理演算の静止姿勢から読み取り（d4は頂点読み、壁寄りは揺すって再判定）。d10は実物と同じ五角偏方面体（凧形10面、全頂点が同一球面上）で、向かい合う面の和は11になります。遊びモードでは跳ね返り／摩擦／投げの強さのスライダーが物理パラメータに即時反映され、「転がし続ける」→「止める」で減衰させて確定します。アニメーションOFFでも物理計算は行い、静止結果のみ表示します。
- どちらの版も、元の Muse スペース版のソースコードの直接エクスポートではなく、仕様・挙動を維持した静的移植です（元の保存処理は Muse の実行環境依存のため、そのままでは外部で動作しません）。
